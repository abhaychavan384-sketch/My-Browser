# MyBrowser

A simple mobile-friendly browser/search web app made with HTML, CSS and JavaScript.

## GitHub Pages
1. Create a new GitHub repository, for example `mybrowser`.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your Pages URL.

## Important
This is a web app/search interface. A GitHub Pages site cannot become a full Chrome-like browser because normal web security rules (CORS, iframe restrictions, etc.) prevent arbitrary websites from being embedded or controlled inside it.
